# 示例：情景计划制定

本示例演示如何基于分析结果制定条件化的情景计划。

## 情景计划原则

1. **使用 If/Then 结构**：明确触发条件
2. **包含失效条件**：什么情况下推翻判断
3. **避免确定性语言**：用"偏向"而非"必定"
4. **可验证**：条件必须可观测

---

## 示例 1：多头情景计划

### 分析结论

```
市场状态：弱多头
- POC: 17.00
- 现价: 17.80
- 支撑: 17.00-17.20 (HVN)
- 阻力: 18.50 (前高)
```

### 情景计划

#### 情景 A：继续上行

**触发条件**：
- 价格回踩 17.20-17.40 区域
- 回踩过程中出现买方堆叠失衡
- 或 Delta 转正 + 缩量

**推断**：支撑有效，偏向继续上行

#### 情景 B：突破走强

**触发条件**：
- 价格突破 18.50 并收盘站稳
- Delta 放大确认
- 无明显上影线

**推断**：阻力突破，价值区上移

#### 情景 C：失效回调

**触发条件**：
- 价格跌破 17.00（POC）
- 且连续 2 根 K 线收于下方
- 或出现卖方堆叠失衡

**推断**：观点失效，需重新评估

## 示例 2：空头情景计划

### 分析结论

```
市场状态：弱空头
- POC: 35.00
- 现价: 44.00（大幅偏离）
- 支撑: 40.00 (前期回调低点)
- 阻力: 47.00 (前高 + 卖方失衡区)
```

### 情景计划

#### 情景 A：反弹遇阻

**触发条件**：
- 价格反弹至 46-47 区域
- 出现卖方堆叠失衡
- 或 Delta 转负 + 放量

**推断**：阻力有效，偏向回落

#### 情景 B：回调确认

**触发条件**：
- 价格跌破 40.00
- 且反抽不过
- Delta 持续为负

**推断**：下降趋势确认，目标 35.00

#### 情景 C：失效反转

**触发条件**：
- 价格突破 47.00 并站稳
- 买方堆叠失衡出现
- Delta 强正

**推断**：空头观点失效，转为多头思路

## 示例 3：震荡情景计划

### 分析结论

```
市场状态：震荡
- POC: 21.00
- 区间: 20.50 - 21.80
- 价值区边界明确
```

### 情景计划

#### 情景 A：向上突破

**触发条件**：
- 价格突破 21.80 并站稳
- Delta 放大确认
- 成交量明显增加

**推断**：突破有效，转为多头

#### 情景 B：向下突破

**触发条件**：
- 价格跌破 20.50 并被接受
- Delta 持续为负
- 无快速反弹

**推断**：突破有效，转为空头

#### 情景 C：维持震荡

**触发条件**：
- 尝试突破上/下沿失败
- 价格回归 POC 附近
- 成交量维持低迷

**推断**：继续等待方向选择

## 情景计划模板

```markdown
### 情景 X：[情景名称]

**触发条件**：
- 价格条件：[具体价位/动作]
- 确认信号：[Delta/Imbalance/成交量]
- 时间要求：[可选，如"连续 N 根 K 线"]

**推断**：[得出的结论]

**应对**：[偏向的操作方向，非具体建议]
```

---

## 避免的表述

❌ 错误示例：
- "明天会涨到 20"
- "建议追涨"
- "必须止损"

✅ 正确示例：
- "如果价格回踩 18.00 出现买方失衡，则偏向继续上行"
- "跌破 17.00 且被接受，则观点失效"
- "突破 20.00 且站稳，价值区可能上移"
