# 示例：Delta 分析与背离识别

本示例演示如何解读 Delta 数据和识别背离信号。

## Delta 基础解读

| Delta 状态 | 含义 | 市场信号 |
|------------|------|----------|
| 正 Delta + 放量 | 主动买入 > 主动卖出 | 买方发起进攻 |
| 负 Delta + 放量 | 主动卖出 > 主动买入 | 卖方发起进攻 |
| 正 Delta + 缩量 | 买方占优但力度弱 | 动能衰减 |
| Delta → 0 | 主动买卖平衡 | 犹豫/整理 |

---

## 示例 1：Delta 确认趋势

### 观测数据

```
上涨过程中：
- K1: 价格涨 2%，Delta +3.5M，成交量 8M
- K2: 价格涨 1.5%，Delta +4.2M，成交量 9M
- K3: 价格涨 2.5%，Delta +5.1M，成交量 10M
```

### 分析

✅ **趋势健康**

- 价格上涨 + Delta 持续扩大 → 买方主导且动能增强
- 成交量递增 → 参与度提高
- 无背离 → 趋势可能延续

---

## 示例 2：Delta 背离（买方衰竭）

### 观测数据

```
上涨过程中：
- K1: 价格创新高 19.00，Delta +4.0M
- K2: 价格创新高 19.50，Delta +2.5M  ← 走弱
- K3: 价格创新高 19.80，Delta +1.2M  ← 明显衰减
```

### 分析

⚠️ **买方衰竭信号**

- 价格持续创新高
- 但 Delta 逐步走弱（4.0 → 2.5 → 1.2）
- **背离形成**：价格走强 vs Delta 走弱

### 推断

- 主动买盘动能衰减
- 可能是：
  1. 买方力竭（Exhaustion）
  2. 上方有吸收（Absorption）
- 警惕反转风险

---

## 示例 3：Delta 背离（卖方衰竭）

### 观测数据

```
下跌过程中：
- K1: 价格创新低 35.00，Delta -5.0M
- K2: 价格创新低 34.50，Delta -3.2M  ← 走弱
- K3: 价格创新低 34.00，Delta -1.5M  ← 明显衰减
```

### 分析

⚠️ **卖方衰竭信号**

- 价格持续创新低
- 但 Delta 负值缩小（-5.0 → -3.2 → -1.5）
- **背离形成**：价格走弱 vs 卖压减轻

### 推断

- 主动卖盘动能衰竭
- 可能是：
  1. 卖方力竭
  2. 下方有买方吸收
- 关注反弹机会

---

## 示例 4：Effort vs Result

### 场景 A：努力有结果

```
大阳线：
- 实体涨 3%
- 成交量 12M（高于平均）
- Delta +6M（强正）
```

**解读**：放量 + 大涨 + Delta 确认 → 有效突破

### 场景 B：努力无结果

```
长上影线：
- 实体仅涨 0.5%
- 成交量 15M（非常高）
- Delta +2M（相对弱）
```

**解读**：
- 放量但涨幅小 → 努力与结果不匹配
- 上影线长 → 上方有抛压吸收了买盘
- 这是**吸收信号**，需警惕

---

## Delta 分析清单

1. **先看方向**：正 or 负？
2. **再看强度**：与历史比是放大还是缩小？
3. **对比价格**：是否有背离？
4. **看成交结果**：Effort 是否有 Result？
