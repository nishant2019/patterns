# 示例：Footprint 微观分析

本示例演示如何解读足迹图中的 Imbalance（失衡）信号。

## Imbalance 基础

Imbalance 表示某个价位上主动买/卖显著超过对手方，通常按 3:1 阈值判定。

| 类型 | 定义 | 含义 |
|------|------|------|
| 买方失衡 | Ask 成交量 ≥ 3× Bid 成交量 | 该价位买方主导 |
| 卖方失衡 | Bid 成交量 ≥ 3× Ask 成交量 | 该价位卖方主导 |
| 堆叠失衡 | 连续 ≥3 档同方向失衡 | 强烈的单边力量 |

---

## 示例 1：买方堆叠失衡（Initiation）

### 观测数据

```
某根上涨 K 线的 Footprint：

价格    Bid x Ask
18.05   120 x 580  ← 买方失衡 (580/120 = 4.8)
18.04   100 x 420  ← 买方失衡 (420/100 = 4.2)
18.03    85 x 350  ← 买方失衡 (350/85 = 4.1)
18.02   200 x 280
18.01   150 x 200
```

### 分析

✅ **买方发起信号**

- 18.03-18.05 连续 3 档买方失衡 → **堆叠失衡**
- 失衡方向与 K 线方向一致（收涨）→ **Initiation**
- 买方在此区域大力扫货

### 交易含义

- 18.03 成为短期支撑
- 回踩到 18.03 附近可能获得支撑
- 失守 18.03 则需重新评估

---

## 示例 2：卖方堆叠失衡（Initiation）

### 观测数据

```
某根下跌 K 线的 Footprint：

价格    Bid x Ask
35.50   450 x 100  ← 卖方失衡 (450/100 = 4.5)
35.49   520 x 120  ← 卖方失衡 (520/120 = 4.3)
35.48   380 x  90  ← 卖方失衡 (380/90 = 4.2)
35.47   200 x 180
35.46   150 x 160
```

### 分析

⚠️ **卖方发起信号**

- 35.48-35.50 连续 3 档卖方失衡 → **堆叠失衡**
- 失衡方向与 K 线方向一致（收跌）→ **Initiation**
- 卖方在 35.50 附近大力出货

### 交易含义

- 35.50 成为短期阻力
- 反弹到 35.50 附近可能遇阻
- 突破 35.50 且站稳则失效

---

## 示例 3：失衡但吸收（Absorption）

### 观测数据

```
长上影 K 线的 Footprint（影线部分）：

价格    Bid x Ask
20.00   150 x 680  ← 买方失衡
19.99   120 x 520  ← 买方失衡
19.98   100 x 450  ← 买方失衡
（收盘价 19.85，这些失衡在影线内）
```

### 分析

⚠️ **吸收信号**

- 19.98-20.00 有买方堆叠失衡
- **但**：收盘价 19.85 远低于失衡区
- 失衡方向与收盘方向**相反** → **Absorption**
- 解读：买方努力进攻，但被卖方吸收，价格退回

### 交易含义

- 20.00 附近有强卖压
- 买方攻势被化解
- 短期偏空

---

## 示例 4：影线成交分析

### 高成交影线（吸收）

```
K 线：开 35.00，最高 35.80，收 35.10
影线区域 35.50-35.80 成交量占全 K 线 40%
```

**解读**：
- 大量成交在影线（未被保留的区域）
- 价格冲高后回落 → 上方抛压被充分成交
- 这是**顶部吸收**信号

### 低成交真空穿越

```
K 线：开 18.00，收 19.50（大阳线）
中间价位 18.20-19.20 成交量极少
```

**解读**：
- 中间无人抵抗 → 真空快速穿越
- 买方没有遇到有效卖压
- 强势信号，但回踩时可能也会快速穿越（无支撑）

---

## Footprint 分析清单

1. **找堆叠失衡**：连续 ≥3 档同方向
2. **对比收盘方向**：
   - 一致 → Initiation（发起）
   - 相反 → Absorption（吸收）
3. **关注影线成交**：高成交影线 = 潜在吸收
4. **标记关键价位**：失衡起始位作为支撑/阻力参考
