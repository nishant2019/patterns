# 示例：识别关键价位

本示例演示如何从 Volume Profile 中识别关键价位。

## 核心概念

| 术语 | 定义 | 交易意义 |
|------|------|----------|
| **POC** | 成交量最大的价位 | 价值中枢，多空平衡点 |
| **HVN** | 成交量密集区 | 潜在支撑/阻力，价格容易在此停留 |
| **LVN** | 成交量稀薄区 | 价格快速穿越区域（真空） |
| **价值区** | 约 70% 成交量集中区域 | 市场接受的公允价格范围 |

---

## 示例：识别支撑位

### 观测数据

```
Volume Profile 显示：
- POC: 66.00
- HVN: 65.00-67.00（密集成交区）
- LVN: 68.00-70.00（稀薄区）
- 现价: 69.00
```

### 分析推理

1. **65.00-67.00 是 HVN**
   - 大量成交发生于此 → 多空充分博弈
   - 买方在此建仓 → 价格回落到此区域可能获得支撑

2. **68.00-70.00 是 LVN**
   - 成交稀少 → 价格快速通过
   - 跌破后可能快速回落到 HVN

3. **POC 66.00 是强支撑**
   - 成交量最大 → 最多人的成本线
   - 跌破 POC 且被接受 → 观点失效信号

### 关键价位输出

| 类型 | 价格区间 | 理由 |
|------|----------|------|
| 第一支撑 | 67.00 | HVN 上沿 |
| 核心支撑 | 66.00 | POC |
| 强支撑 | 65.00 | HVN 下沿 |
| 失效位 | 跌破 65.00 | 价值区下破 |

---

## 示例：识别阻力位

### 观测数据

```
Volume Profile 显示：
- POC: 17.00
- HVN: 16.50-17.50
- 现价: 18.00（已脱离 HVN）
- 前高区域: 18.50-19.00（有历史成交集中）
```

### 分析推理

1. **18.50-19.00 是潜在阻力**
   - 前期高点 → 套牢盘存在
   - 历史成交集中 → 可能形成卖压

2. **当前处于 LVN**
   - 17.50-18.50 成交稀薄
   - 阻力较小，有利上攻

3. **价值迁移确认**
   - 如果 18.50 被突破并站稳 → 新的 HVN 可能形成
   - 价值区向上迁移

### 关键价位输出

| 类型 | 价格区间 | 理由 |
|------|----------|------|
| 第一阻力 | 18.50 | 前高下沿 |
| 强阻力 | 19.00 | 历史套牢盘 |
| 突破确认 | 站稳 19.00 | 价值迁移信号 |

---

## 价位判断原则

1. **HVN 通常形成支撑/阻力**：因为大量交易者的成本在此
2. **LVN 是快速通道**：价格不会在此停留
3. **POC 是核心锚点**：失守 POC 通常意味着控制权易手
4. **结合 Delta 确认**：回落到支撑位时看是否有买方失衡
