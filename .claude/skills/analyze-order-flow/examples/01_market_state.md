# 示例：判断市场状态

本示例演示如何根据可观测数据判断市场处于哪种状态。

## 市场状态分类

| 状态 | 特征 |
|------|------|
| 强多头 | 连续正 Delta + 放量上攻 + 价值区上移 |
| 弱多头 | 正 Delta 但动能减弱 + 上方有阻力 |
| 震荡 | Delta 正负交替 + 缩量 + 价格围绕 POC 波动 |
| 弱空头 | 负 Delta + 高位滞涨 + 价值区下移 |
| 强空头 | 连续负 Delta + 放量下跌 + 跌破 HVN |

---

## 示例 1：强多头

### 观测数据

```
- 现价：18.00（高于 POC 17.00）
- Delta：连续 5 根 K 线正值，最高 +5.2M
- 成交量：递增放大
- VRVP：价格脱离 HVN，进入上方 LVN（真空区）
- K 线形态：实体饱满，影线短
```

### 分析推理

1. **价格位置**：现价 18.00 > POC 17.00 → 多头占优
2. **Delta 确认**：连续正值 + 放大 → 主动买盘强劲，无衰竭
3. **量价配合**：放量 + 价格推进 → 趋势健康
4. **阻力真空**：上方 LVN → 最小阻力路径向上

### 判断结论

**市场状态：强多头**

---

## 示例 2：震荡

### 观测数据

```
- 现价：21.10（接近 POC 21.00）
- Delta：正负交替，无持续方向
- 成交量：整体偏低，无明显放大
- VRVP：收盘价在 POC 附近，成交分布分散
- K 线形态：实体小，上下影线均衡
```

### 分析推理

1. **价格位置**：现价 ≈ POC → 多空平衡
2. **Delta 无方向**：正负交替 → 缺乏主导力量
3. **缩量**：参与度低 → 观望情绪浓
4. **K 线混乱**：重叠度高 → 无趋势

### 判断结论

**市场状态：震荡**

---

## 示例 3：弱空头

### 观测数据

```
- 现价：44.00（大幅偏离 POC 35.00）
- Delta：高位出现负值，由正转负
- 成交量：放大但价格滞涨
- VRVP：筹码集中在 33-38，现价处于高位真空
- K 线形态：上影线长，顶部成交密集
```

### 分析推理

1. **价格偏离**：现价远离价值中枢 → 超涨，回调压力大
2. **Delta 转负**：高位派发信号
3. **放量滞涨**：Effort vs Result 不匹配 → 吸收迹象
4. **上影线长**：顶部卖压重

### 判断结论

**市场状态：弱空头**
